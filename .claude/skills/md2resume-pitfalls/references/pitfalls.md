# md2resume 踩坑参考

## 症状 → 原因 → 处理

| 症状 | 原因 | 处理 |
|---|---|---|
| 参考模板做出的 DOCX 再转 PDF 报受限字体 | 模板 XML 未使用宏样式带有独立 `Courier` | 精确净化：`Courier` → `Arial`；保留 `Courier New` |
| 内容增加后从 1 页变成 2 页 | DOCX 不会在生成阶段自动测算分页 | 用 Word/LibreOffice 实际渲染计页，逐档调 `scale`，再检查底部 |
| Playwright 已安装但无法预览 | Python 包在，Chromium 可执行文件不在 | 主流程不要依赖浏览器；QA 用本机 Word/LibreOffice |
| 关键构建逻辑找不到 | 高质量脚本曾放在 `tmp/resume/` | 把稳定脚本提升到 `scripts/`，临时目录只放可删草稿 |
| 生成结果含真实个人信息 | 参考模板打包了姓名、联系方式或照片 | 仓库只放脱敏模板；真实模板通过 `--reference` 传入 |
| 目标 DOCX 无法覆盖 | WPS/Word 打开文件产生锁文件 | 先检查占用；关闭文件或改用新输出名 |
| 结果样式不统一 | 成果行没有固定识别规则 | 每段最后一条成果用 `> ` 标记，统一浅蓝底和左蓝条 |
| 交付目录混入 PDF/图片/HTML | 旧的多格式渲染链仍在写文件 | 生成函数只返回 `docx`；QA 中间文件放临时目录并清理 |

## 证据边界

以上规则来自 md2resume 项目 2026-07-18 至 2026-08-05 的 Claude Code 会话日志。日志中的个人路径、姓名、联系方式、令牌和图片 URL 不复制到 Skill；只保留可迁移的工程经验。

## 推荐默认值

- 路径 A（参考模板克隆）：`--scale 0.99`（内容变长溢出后再降到 `0.90`）
- 路径 B（`build_b_resume.py` 且 dense）：内部建议 `scale=0.90`
- 交付目录允许扩展名：`.docx` only
